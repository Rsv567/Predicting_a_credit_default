# Прогнозирование кредитного дефолта с использованием машинного обучения

## Введение

### Проблема
Банки и финансовые учреждения сталкиваются со значительными рисками при выдаче кредитов. Традиционные методы оценки кредитоспособности часто оказываются:
- Недостаточно точными для нетипичных заемщиков
- Субъективными в принятии решений
- Неэффективными при работе с дисбалансированными данными

### Цели проекта
1. Разработать модель прогнозирования дефолтов с точностью выше 70%
2. Создать интерпретируемую систему оценки рисков
3. Автоматизировать процесс обработки кредитных заявок
4. Уменьшить финансовые потери от "плохих" кредитов на 15-20%

## Данные и предобработка

### Источник данных
Использовался датасет Home Credit Default Risk с Kaggle, содержащий:
- **2000 кредитных заявок** (случайная выборка)
- **122 признака** по трем категориям:

| Категория признаков | Примеры |
|---------------------|---------|
| Демографические | Возраст, пол, семейное положение |
| Финансовые | Доход, сумма кредита, наличие имущества |
| Кредитная история | Количество займов, просрочки, внешние скоринги |

### Ключевые этапы обработки данных
1. **Анализ дисбаланса классов**:
   - 91.3% - своевременное погашение
   - 8.7% - дефолт (просрочка >90 дней)

2. **Обработка пропусков**:
   - Числовые признаки: заполнение медианой
   - Категориальные: замена на "missing"

3. **Преобразование признаков**:
   - Стандартизация числовых переменных
   - One-Hot кодирование категориальных

## Методы и моделирование

### Тестируемые алгоритмы
1. **Логистическая регрессия** (базовая модель)
2. **Случайный лес** (ансамблевый метод)
3. **XGBoost** (градиентный бустинг)
4. **Оптимизированный XGBoost** (с подбором гиперпараметров)

### Борьба с дисбалансом классов
- Использование параметра `scale_pos_weight` (соотношение 10.5:1)
- Фокус на метрики:
  - **ROC-AUC** (качество разделения классов)
  - **Precision-Recall** (точность предсказания дефолтов)

## Результаты

### Сравнение моделей

| Модель               | ROC-AUC | Precision | Recall | F1-score |
|----------------------|---------|-----------|--------|----------|
| Logistic Regression  | 0.652   | 0.155     | 0.494  | 0.236    |
| Random Forest        | 0.656   | 0.0       | 0.0    | 0.0      |
| XGBoost              | 0.667   | 0.2       | 0.017  | 0.031    |
| **XGBoost (Optuna)** | **0.703**| **0.25** | **0.12**| **0.16** |

### Интерпретация модели
**Топ-5 значимых признаков**:
1. EXT_SOURCE_3 (внешний кредитный скоринг)
2. DAYS_BIRTH (возраст заемщика)
3. EXT_SOURCE_2 (внешний скоринг)
4. AMT_CREDIT (сумма кредита)
5. DAYS_EMPLOYED (трудовой стаж)

**Ключевые зависимости**:
- 📉 Высокий EXT_SOURCE → Низкий риск
- 📈 Молодой возраст → Высокий риск
- 💰 Большая сумма кредита → Повышенный риск
